# Home News (backend) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: superpowers:subagent-driven-development or superpowers:executing-plans, plus the model-orchestration skill. TDD throughout; no live network in tests (GDELT, NSE and any publisher are faked with fixtures). **No code starts until the owner says go.**

**Goal:** one new scheduled job that ingests GDELT news files into a shared table, and a `GET /home/news` endpoint that scores and returns one to three items per user at request time. The card UI is in `2026-10-23-home-frontend-plan.md` (T10). Research and rules: the decision record `Docs/orchestration/2026-10-23-portfolio-snapshot-decisions-v20.html` section 5 and appendix (L9-L18, L40, L41, E-series), spec section 8.

**Decisions this plan relies on:** GDELT raw GKG 15-minute files only (L15, E13); English titles only (E16); job every 3 hours plus one daily catch-up (E19); top 5 per kind plus minimum-size rule, values calibrated and shown to the owner before locking (L17, E20); strict ladder stocks, fund categories, fund houses, asset class or commodity, sectors, rates and macro, general (L40) with majority-class override (L41); gold and silver one topic (E18); foreign-stock news only for holders (L18); a headline stays 24 hours from publication, no timer refresh (L10-L13, E22); exposure chip only at 50% coverage or more with a dynamic "holdings as of <Mon YYYY>" (E9); `stock_master.nse_symbol` column and a Healthchecks.io heartbeat (E11 B); GDELT credit on the About/legal page only (E14 B); **live from day one with the disclaimer, `news_enabled` kill switch kept (N5 B)**.

**Branch:** `feat/home-news` from updated `feat/leapswitch-staging` (or inside `feat/home-snapshot` if the owner prefers one branch). New files plus: a migration, one cron file line set, `app/main.py` registration, the legal page text. No commit or push without the owner's word.

**Test commands:** `cd backend && .venv/Scripts/python.exe -m pytest <file>`.

## Files

`app/models/news.py` (`NewsItem`), `app/services/news/{ingest,normalise,match,score,config}.py`, `scripts/jobs/refresh_news.py`, `app/api/home_news.py` (or inside `api/home.py`), migration `00NN_news_items_and_nse_symbol`, tests under `tests/services/news/` and `tests/api/`, `deploy/leapswitch/crontab.leapswitch` lines, `frontend/src/features/legal/` About text.

## Tasks

- [ ] **T1 VM dry run (E4).** Before building, one read-only run on the VM that downloads the latest few hours (about 6) of GDELT files, writes nothing, and reports whether the VM can reach GDELT, how long it took and how much memory it used. A small throwaway script under `backend/scripts/` run by the manager like `measure_home_staging.py`. Go or no-go for the rest.
- [ ] **T2 Model and migration.** Test first (`tests/test_migrations.py` pattern and a model test): table `news_items` (id, source, title, url unique, published_at, language, entity tags as JSON, tier, ingested_at) and nullable `stock_master.nse_symbol`. Next free migration number (check `alembic heads`); Postgres-only parts in `tests/functional_postgres`. Update the schema doc at the end.
- [ ] **T3 Ingest.** `ingest.py` reads 15-minute GKG files in a streaming way (never loads a whole file), only files at least an hour old, retry on missing, from fixtures in tests (`tests/fixtures/gdelt/`). Tests: parses fixture rows, skips non-English titles, applies the allow-list of Indian business sites (Moneycontrol, Mint, Business Standard, BusinessLine, ET markets) plus the small global allow-list used only for foreign names, deduplicates by URL, handles a 404 file and a truncated file.
- [ ] **T4 Normalise and tag.** Map each article to entity tags: held-style stocks (names, ISINs, `nse_symbol` when present; the matcher must work without it), fund houses, SEBI categories, asset classes (gold and silver one topic), sectors, rates and macro, general. Tests on a hand-labelled set of headlines (calibrate precision for gold, rates, banking, sectors, categories; record the numbers).
- [ ] **T5 Match and score (request time).** Per user and scope, from stored holdings and look-through: top 5 of each kind by size, only entities above the minimum size (E20; calibrate on the synthetic set and show the owner the numbers before they are locked); strict ladder fills up to three slots from the highest tier with news, no two items about the same entity, newest first inside a tier; majority-class override when one asset class holds the majority; foreign names only for holders; exposure percentage from look-through with coverage rule (chip omitted under 50% coverage, "holdings as of" from the disclosure date actually used). Tests for each rule, including a debt-only user falling through to rates, a user with no specific match getting general news, and "keep the last specific item for 24 hours from publication then general news".
- [ ] **T6 Job `refresh_news.py`.** Runs ingest and writes `news_items`; honours `news_enabled`; pings Healthchecks.io (`HEALTHCHECK_NEWS_URL` from `.env`, absent in tests, called only on success, never with user data); logs counts. Tests: success path pings once, failure path does not, kill switch skips ingest. Cron lines in `deploy/leapswitch/crontab.leapswitch` (every 3 hours between 07:00 and 22:00 IST plus one catch-up run) through `run-job.sh`, one wrapper line per run, spaced away from the 05:45-06:30 batch window (memory budget: see the staging plan). Equivalent AWS EventBridge schedule is out of scope unless the owner asks.
- [ ] **T7 Endpoint.** `GET /home/news` (auth required; scoped like the other Home routes; loads separately and never blocks other sections). Returns up to three items with kind, source, time ago basis (`published_at`), headline, URL, category icon key, exposure percentage or null, reason text, funds involved, and flags `stale` (over 36 hours) and `hidden` (over 72 hours). Tests: auth, scope, kill switch off returns an empty list, stale and hidden flags.
- [ ] **T8 Legal and disclaimer copy.** About/legal page credit "News index: GDELT Project" with link; neutral subtext and disclaimer strings for the card; all go on the F5 copy review list for the owner and counsel.
- [ ] **T9 Staging check.** Run the job by hand a couple of times on staging, review real matches for noise, check memory and duration on the VM, then enable the cron lines. Counsel review of the card wording was recommended; the owner chose it is not a launch gate, the kill switch stays so the card can be turned off immediately.

## Risks

GDELT has no service guarantee and its coverage of single stocks is thin (hence the ladder and general fallback). VM or cloud IPs may be blocked (T1 settles it). Advice-wording and publisher-copyright exposure (neutral wording, no sentiment, link out only). Heartbeat service is a small third-party dependency that receives no user data.
