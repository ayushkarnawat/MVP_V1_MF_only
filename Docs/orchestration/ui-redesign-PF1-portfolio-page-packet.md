### Step 2: `portfolioFormat.ts` and `portfolioCopy.ts`
Pure functions; read both test files (`portfolioFormat.test.ts` 47 tests, `portfolioCopy.test.ts` 17 tests).

**`portfolioFormat.ts`:**
- `changeDirection(value: string | null | undefined): "up" | "down" | "flat"`: null, empty, unreadable (not `^[+-]?\d+(\.\d*)?$` after trim) or all-zero digits (`0`, `0.00`, `-0.00`) give `flat`; otherwise `down` when it starts with `-`, else `up`.
- `formatSignedRupees(value)`: `formatRupees(value)`; return it unchanged when it is `—`, `₹0` or starts with `-`; otherwise prefix `+` (`12.00` gives `+₹12`, `-0.40` gives `₹0`).
- `formatSignedPercent(value, digits = 2)`: `formatPercent(value, { digits, signed: true })`.
- `formatXirr(value)`: `—` for null; otherwise `formatPercent(toPercentString(value), { digits: 1 })` (the backend XIRR is a decimal fraction: `0.3488967977667153354496159637` gives `34.9%`; never multiply).
- `todayGainLine(gain: string, pct: string | null): string`: `Today's Gain: ${formatSignedRupees(gain)}` and, when `pct` is not null, ` (${formatPercent(pct, { digits: 2 })})` (unsigned in the brackets, so `-0.0004` prints `0.00%`).
- `partialChipText(missing: MissingFund[])`: `""` for none, else `` `${missing.length} on last known NAV` ``.
- `shareOf(value: string, total: string): string | null`: exact four-place percentage string rounded half up, done in `BigInt` paise: parse each as `^(-?)(\d+)(\.\d*)?$` (null result when unreadable), paise = whole digits followed by the fraction padded or cut to two digits, negated for `-`. A total of zero or less gives `null`; a negative value counts as zero. Result: `scaled = (value * 1000000n + total / 2n) / total`, printed as `${scaled / 10000n}.${(scaled % 10000n) padded to 4 digits}` (`1.00` of `3.00` gives `33.3333`; `2.00` of `3.00` gives `66.6667`; `10.00` of `10.00` gives `100.0000`; `0.00` of `10.00` gives `0.0000`).
- `memberTitleName(name)`: unchanged when it contains a lower-case letter; otherwise lower-case it and upper-case the first letter of each word (`ASHA RAO` gives `Asha Rao`, `ASHARAO` gives `Asharao`); empty stays empty.
- `memberInitials(name)`: upper-case first letters of up to the first two words (`Dev  Kumar Rao` gives `DK`, `ASHARAO` gives `A`); `?` when there is no word.
- `memberColor(index)`: `` `var(--c${(index % 8) + 1})` ``.

**`portfolioCopy.ts`:** export `interface SliceRow { key: string; label: string; percentage: string; value: string; color: string }`.
- `bucketKey(label)`: lower-case, `&` becomes `and`, every run of non-alphanumerics becomes one `-`, leading and trailing dashes removed (`FDs & Bonds` gives `fds-and-bonds`, `Mutual Funds` gives `mutual-funds`).
- `bucketColor(label)`: `Mutual Funds` `var(--c1)`, `Direct Stocks` `var(--c3)`, `US Stocks` `var(--c4)`, `FDs & Bonds` `var(--c5)`, `Debt` `var(--c2)`, `Gold` `var(--c6)`, `Real Estate` `var(--c7)`; anything else (including `Others`) `var(--ui-text-muted)`.
- `bucketPath(label)`: from `paths`: `Mutual Funds` `paths.mutualFunds.root()`, `Direct Stocks` `paths.equity.directStocks()`, `US Stocks` `paths.equity.usStocks()`, `FDs & Bonds` `paths.equity.fdsBonds()`, `Debt` `paths.debt()`, `Gold` `paths.gold()`, `Real Estate` `paths.realEstate()`, `Others` `paths.others()`; unknown label gives `null`.
- `liveTotal(buckets)`: `sumDecimalStrings` of `current_value ?? "0"` over buckets whose `status` is `live` (`5212.00` for the family fixture; `0` when none is live).
- `visibleBuckets(buckets, filter: "all" | "live")`: all, or only live.
- `sortBuckets(buckets, order: "asc" | "desc")`: a **new** array sorted by `percentage ?? "0"` with `compareDecimalStrings` (negated for `desc`), stable so equal values keep the backend order in both directions.
- `sliceRows(buckets): SliceRow[]`: for live buckets with a non-null percentage above zero, in the backend order: `{ key: bucketKey(label), label, percentage, value: current_value ?? "0", color: bucketColor(label) }`.
- `isEmptyPortfolio(summary)`: true only when `total_value` and `total_invested` are both zero or less (`compareDecimalStrings`).
- `sparkPoints(points: ValuePoint[]): string`: `""` for fewer than two points. Otherwise the values as numbers (geometry only); `x = round1(index * 72 / (n - 1))`; `y = 13` when min equals max, else `round1(24 - (value - min) / (max - min) * 22)`; `round1 = x => Math.round(x * 10) / 10`; the points joined as `x,y` with single spaces (`[100,150,200]` gives `0,24 36,13 72,2`).
- `sparkTrend(points)`: `flat` for fewer than two points; otherwise `up`, `down` or `flat` from `compareDecimalStrings(last.value, first.value)`.
