- `outperformText(gap: string): string`: `Behind` when `compareDecimalStrings(gap, "0") < 0`, otherwise `Outperformed`; then ` by ${magnitude} percentage points` where `magnitude` is the gap without its sign shown to one decimal: `formatPercent(gap.replace(/^[+-]/, ""), { digits: 1 })` with the `%` removed (`13.11` gives `Outperformed by 13.1 percentage points`, `-2.00` gives `Behind by 2.0 percentage points`, `0.00` gives `Outperformed by 0.0 percentage points`).

**`scenarioFormat.ts`.** Export `type Tone = "gain" | "loss" | "neutral"` and:
- `toneOf(value: string | null | undefined): Tone`: `neutral` for null, undefined, unreadable (not `^[+-]?\d+(\.\d*)?$` after trim) and zero (`0.00`, `-0.00`); `loss` below zero; `gain` above (use `compareDecimalStrings`).
- `signedPct(value: string | null, digits = 1): string`: `—` for null; otherwise `formatPercent(value, { digits, signed: true })` with every `-` replaced by the real minus `−` (U+2212) (`-1.2` gives `−1.2%`, `0` gives `0.0%`, `12.34` with 2 gives `+12.34%`, `-0.04` gives `0.0%`, `abc` gives `—`).
- `signedRupees(value: string | null): string`: `formatRupees(value)`; return it unchanged when it is `—` or `₹0`; otherwise replace a leading `-` by `−`, or prefix `+` (`-459.80` gives `−₹460`, `100.82` gives `+₹101`, `-0.40` gives `₹0`, `-1266600` gives `−₹12,66,600`).
- `outperformedBy(portfolioPct: string | null, benchmarkPct: string | null): string | null`: null if either is null, otherwise `formatDecimal(diffDecimalStrings(portfolioPct, benchmarkPct))` (exact two decimals: `("-17.09","-30.20")` gives `13.11`, `("0.10","0.20")` gives `-0.10`, `("-0.00","0.00")` gives `0.00`; never a float).
- `interface BarScale { zero: number; widths: number[]; sides: ("left" | "right")[] }` and `barScale(values: string[]): BarScale` (geometry, percent of the track): `numbers = values.map(Number)`, `min = Math.min(0, ...numbers)`, `max = Math.max(0, ...numbers)`, `range = max - min || 1`; `zero = max <= 0 ? 100 : min >= 0 ? 0 : (-min / range) * 100`; `widths = numbers.map(n => Math.abs(n) / range * 100)`; `sides = numbers.map(n => n < 0 ? "left" : "right")` (`["-10","5"]` gives zero about 66.67, widths 66.67 and 33.33; all negative gives zero 100; all positive gives zero 0; all zero gives widths of 0).
- `resolveShape(scenario: ScenarioSummary): ResultShape`: `hypothetical` when `scenario_type` is `HYPOTHETICAL`; else `redemption_freeze` when `had_redemption_freeze_schemes` has at least one entry; else `multi_phase` when `parent_scenario_id === null && has_phases`; else `standard`.
- `benchmarkLabel(name: string): string`: `nifty_50` `Nifty 50`, `nifty_500` `Nifty 500`, `nifty_largemidcap_250` `Nifty LargeMidcap 250`, `nifty_midcap_150` `Nifty Midcap 150`, `nifty_smallcap_250` `Nifty Smallcap 250` (use `Object.hasOwn`); another name containing `_` becomes its words capitalised and joined by spaces (`some_new_index` gives `Some New Index`); another name is returned unchanged.
- `titleName(name: string): string`: unchanged when it contains a lower-case letter; otherwise lower-case it and upper-case the first letter of each word (`ASHA RAO` gives `Asha Rao`); empty stays empty.
- `slugify(label: string): string`: trim, lower-case, every run of non-alphanumerics becomes one `-`, leading and trailing dashes removed (`Gold and Silver` gives `gold-and-silver`).
