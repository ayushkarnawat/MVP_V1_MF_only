### Step 2: `data/analyticsStore.ts` and `data/useMfDashboard.ts`

**`data/analyticsStore.ts`:** exports `StoreState` (`{ sections, recomputing, fetchError, loadedAt }`), `analyticsStore` and `useMfAnalytics`.
- Module-level cache `Map` keyed by `` `${getToken() ?? ""}|${scope}` `` (a second user on the same browser never sees the first one's payload); each entry holds its `state`, its `listeners`, the in-flight promise and the poll timer. The state of an unknown scope is one frozen shared `EMPTY = { sections: {}, recomputing: false, fetchError: null, loadedAt: null }` (the same object every time).
- `refresh(scope): Promise<void>`: one request per scope at a time (return the in-flight promise); on success `state = { sections, recomputing, fetchError: null, loadedAt: Date.now() }` then schedule polling; on failure `state = { ...state, fetchError: error message (or "Failed to load analytics data") }` (the earlier sections stay); always clear the in-flight promise and call every listener.
- Polling: `POLL_MS = 3000`. After a successful fetch, if the entry has at least one listener and (`recomputing` or some name of `ANALYTICS_SECTION_NAMES` is not settled, settled = `payload !== null || failed_at !== null`), start one timer that calls `refresh` again. The timer is cleared when the last listener leaves. No polling without a listener (even if an answer arrives after the last one left).
- `subscribe(scope, listener)`: add the listener; fetch when nothing is loaded or the payload is older than 5 minutes (`FRESH_MS`), otherwise just resume polling if needed; return the unsubscribe function. `getSnapshot(scope)`: the entry's state, or `EMPTY`. `invalidate(scope?)`: with a scope reset that scope's entries (state back to `EMPTY`, timer cleared, in-flight dropped); without one reset all.
- `AGGREGATE_FIELD` (module-local, copied from the old analytics screen): `allocation: "allocation"`, `stock_holdings: "stock_holdings"`, `valuation: "valuation"`, `overlap: "overlap"`, `asset_allocation: "asset_allocation"`, `cap_allocation: "cap_allocation"`, `ter: "ter"`, `ter_direct_regular: "ter"`, `benchmark: "benchmark"`, `benchmark_funds: "comparison"`, `category_ranking: "ranking"`, `ranking: "ranking"`, `score: "score"`, `investment_withdrawal: "data"`, `fund_manager: "fund_manager"`.
- `useMfAnalytics(name)`: reads `useScope()`; the scope is `"combined"` in the family view and the member id in a member view (none: nothing happens). Use `useSyncExternalStore` with `analyticsStore.subscribe(scope, ...)` and `getSnapshot(scope)`.
