## 5. Gotchas learned this session (these cost time)
- **PowerShell 5.1 and the register:** `Get-Content`/`Set-Content` without an explicit encoding mangled the rupee signs in row C68. Edit the register only with Python in UTF-8 (read bytes, decode utf-8, keep the file's line endings, append rows, write bytes). Always run `git diff --stat` on the register afterwards; a one-row addition must show `1 insertion`.
- `Start-Process powershell -File "<path with spaces>"` silently runs nothing (unquoted path). Run scripts directly in a background command, and do not trust a silent empty output file for more than a minute or two.
- Heavy front-end suites (`src/shell/portedFlow`, `registry`, `App`) time out when anything else loads the machine; the failing test changes run to run. Never run two verifications at once; rerun alone before calling a failure real. Use `--maxWorkers=4`.
- A subagent that stops mid-way keeps its worktree state: resume it with `SendMessage` to its agent id instead of starting over. Subagent-written packets must not touch the register or commit in the docs worktree (you commit them).
- A bash heredoc with a long markdown body failed once; write long files with the Write tool.
- Deleting a remote branch or resetting a worktree needs the owner's word each time. Reports from the manager machine arrive as text only; the owner (or the manager) runs commands there and relays.
