## Explicit gaps and decisions

- WhiteOak/UTI/Groww only accept unambiguous same-row geometry, tested synthetically;
  no geometry or two nearby names means no reading. Owner verifies real PDFs later.
- Franklin reuses the existing verified 132-point left-panel boundary. Its real
  benchmark words are below BENCHMARK and above NAV, separate from the holdings.
- A page with several scheme headings is skipped rather than assigning one index
  to several funds. A page without an established scheme heading is also skipped.
- Some manager-only excerpts contain no reliable benchmark declaration (including
  Bandhan, Invesco, JM, Angel, Baroda, BOI, ASK, Mahindra, Old Bridge, Samco, Union,
  Wealth). This is missing fixture evidence, not proof that their real PDFs lack it.
- Only Axis's clearly headed lump-sum table is verified for printed returns here:
  “Period / 1 Year 3 Years 5 Years Since Inception”. Values 1.99%, 10.58%, 9.63%
  come from BSE 100 TRI (Benchmark), not the scheme, Additional or SIP rows.
  Other table orders and SIP tables fail closed; they need verified per-house
  table rules before their printed figures can be populated. No guessed returns.
- verified_on means import/verification date; mapping_age_days is elapsed days
  since that date. printed_as_of remains the factsheet's own date.
- Printed returns are percentages in Numeric(12,6), used only for fixed-period
  inception-mode benchmark rows with the printed date shown. Current holding XIRR
  and every daily-series reader never select those columns.
- Legacy replay behaviour is retained for old stored numbers. Missing-history,
  oversale, opening-date and fully-sold guards are applied to declared_comparison.

- Review regression: tracked_match_quality is stored separately from Tier I
  match_quality. A fund tracking BSE Sensex must retain a closest-index label
  when the chosen daily series is Nifty 50; a tracked key never implies an
  exact match merely because that key exists.
