# Navigation shell: test design (TDD, draft v1)

**Status:** draft, 2026-10-23. Doc 5. Red, then green, then refactor (`AGENTS.md`). Run only the test files a change touches: `npx vitest run <file>`; no full suites; no live network. Stack: Vitest 4.1.10 with jsdom and globals, Testing Library for React 16, setup in `src/setupTests.ts` (**verified**). Routed tests use `MemoryRouter` (documented declarative router, **verified**); no end-to-end tool is added (D3 answer). Backend: none (no backend change).

Both modes, light and dark; Equity expand and collapse; a greyed row's tooltip; focus ring on every row with the keyboard; deep link and refresh on `/portfolio/mutual-funds/holdings`; Back after Profile; the scope rule with a two-member synthetic household (`Docs/CAS Files/synthetic/pdfs/realistic/`); `/import` focus layout; narrowing below 768 px switches to the mobile tree.
