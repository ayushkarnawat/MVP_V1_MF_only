## Part B: the dialog (`ExportDialog`)
Build on `components/ui/dialog.tsx` (Radix: focus trap, Escape, overlay already there). **The dialog is presentational**: it keeps only the form state of stage 1 and calls the callbacks. Width: **560 px** for stage 1, **520 px** for stages 2 to 4 (`max-width: calc(100vw - 32px)`); radius 16 px; shadow `0 20px 60px rgba(0,0,0,.3)`; **it must scroll inside itself when the window is short** (`max-height: calc(100vh - 32px)`; stage 1 is taller than a 1280 x 600 window: the title and the footer buttons stay in view, the middle scrolls). Light mode must match the drawing; dark mode follows the app's tokens.
```ts
// exportTypes.ts
export type ExportStage = "choose" | "preparing" | "ready" | "failed";
export type ExportPreset = "full" | "tab" | "custom";
export interface ExportChoice { who: "family" | string /* a member id */; sectionIds: string[]; cover: boolean; dataDates: boolean; showFolios: boolean; }
export interface StageRow { label: string; state: "done" | "now" | "todo"; note?: string }
export interface ExportDialogProps {
  open: boolean; onOpenChange: (open: boolean) => void;
  stage: ExportStage;
  members: { id: string; name: string }[];          // the household; the dialog adds "Family Combined (n members)" itself
  currentTab: MfTabId | null;                        // null on pages that are not a Mutual Funds tab: "This tab" is then not offered
  defaults: { who: "family" | string; preset: ExportPreset; showFolios: boolean };
  allowedTiers?: ("standard" | "pro")[];             // default both; a tier can hide Pro sections
  onStart: (choice: ExportChoice) => void; onCancel: () => void; onKeepWorking: () => void;
  progress: { subtitle: string; percent: number; rows: StageRow[] };     // stage 2
  ready: { fileName: string; chips: string[] };                          // stage 3: chips e.g. ["14 pages","1.2 MB","Family combined","Full report"]
  onDownloadAgain: () => void; onExportAnother: () => void; onDone: () => void;
  failed: { code: string | null; canTryFewer: boolean; canExportMember: boolean };  // stage 4
  onTryAgain: () => void; onFewerSections: () => void; onPrintInstead: () => void; onExportMember: () => void; onClose: () => void;
}
```
`MfTabId` and `SECTION_LISTS` are from `frontend/src/lib/pageSections.ts` (a `features/` file may import from `lib/`). **The dialog never hard-codes a section or a count**: the checklist, the counts and the presets come from `SECTION_LISTS` (the drawing's counts, such as "Overview (7)" and "26 sections", are examples; today's real list is shorter and may change).
