A summary **without** `windows` (stored before the MB backend; `{}` also counts) is the fallback: window `SI` gives `{ available: true, reason: "ok", startDate: null, portfolio: summary.portfolio_xirr ?? null, indices: <map of summary.benchmarks ?? []> }`; any other window gives the empty view with reason `recomputing`.
- `windowUnavailableText(reason)`: `not_enough_history` (and `ok`) gives `Not enough history for this window yet.`; `recomputing` gives `This window is still being recalculated and will appear after the next analytics refresh.`; `opening_balance_in_window` gives `Unavailable: an opening balance from your statement falls inside this window, so money added and starting value cannot be told apart.`
- `buildEntities(summary, window, selected)`: the portfolio first (`xirr` = the window's portfolio rate), then the selected indices **in `INDEX_DEFS` order** whatever order they were picked in (`xirr` = `view.indices[key] ?? null`).
- `interface TrackMarker { key: EntityKey; x: number; offset: number; above: boolean; crown: boolean }`, `MIN_GAP = 8`, `layoutRaceTrack(entities: { key; xirr }[]): TrackMarker[]`: entities with a null `xirr` get no marker (none left gives `[]`); values are `Number(xirr)` (geometry); `min`, `max`; `x = round2(5 + (value - min) / (max - min) * 90)` and `50` for everything when `max === min` (one entity too), `round2 = Math.round(v * 100) / 100`; the markers come back **sorted ascending by value** (ties by input order); `above` is true for even positions in that order; `crown` is true for the entity with the highest value (the first in input order on a tie); `offset` (pixels, up negative, down positive) is `0` for the first marker and for any marker whose `x` minus the previous marker's `x` is **at least** `MIN_GAP`; otherwise `(position % 2 === 0 ? -1 : 1) * Math.round(6 + (MIN_GAP - gap) / MIN_GAP * 10)`. `x` is never altered by the nudge (it is finance data). Examples: values `0.1000, 0.1005, 0.2000` give `x` 5, 5.45, 95 and offsets 0, 15, 0; `0.0000, 0.0889, 1.0000` give `x` 5, 13, 95 and offsets 0, 0, 0; `0.0000, 0.0888, 1.0000` give 5, 12.99, 95 and offsets 0, 6, 0.
- `barPercent(value: string | null, entities: { xirr: string | null }[]): string`: `"0"` for a null value; otherwise `String(round2(Math.abs(Number(value)) / largest * 100))` where `largest` is the largest absolute `Number(xirr)` among the entities (null counts 0); `"0"` when `largest` is 0. (`100` is `"100"`, half of it `"50"`.)
- `interface FundWindowView { fund: string | null; benchmark: string | null }`; `fundWindow(fund: FundBenchmarkRow, window)`: when the fund has `windows` (not undefined and not empty) the row of that window (`{ fund: row.fund_xirr, benchmark: row.benchmark_xirr }`, nulls when there is no such row); without `windows`, window `SI` gives the top-level `{ fund: fund.fund_xirr, benchmark: fund.benchmark_xirr }` and any other window `{ fund: null, benchmark: null }`.
- `fundDifference(view): string | null`: `diffDecimalStrings(toPercentString(view.fund), toPercentString(view.benchmark))` (`"0.1420"` against `"0.1690"` gives `"-2.70"`), `null` when either is null.
- `fundsForWindow(funds, window): Array<{ fund: FundBenchmarkRow; view: FundWindowView }>`: the funds whose `view.fund` is not null, in the given order.
- `miniTrack(view): { fund: number; benchmark: number } | null`: `null` when either is null; `lo = min`, `span = max - min` of the two `Number`s; `{ fund: 50, benchmark: 50 }` when `span` is 0; else each `round2(5 + (v - lo) / span * 90)` (the lower value sits at 5, the higher at 95).
