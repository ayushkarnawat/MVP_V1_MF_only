# Home and shell: test design (TDD, draft v1)

**Status:** draft, 2026-10-23. Doc 5. Red, then green, then refactor. Run only the test files a change touches; no full suites; no live network (GDELT, NSE, AMFI, mfapi are faked). Backend: `pytest <file>`; frontend: `npx vitest run <file>`. Postgres-only behaviour (enum add) goes in `functional_postgres`.

## 1. Backend (per `services/home/` module)

| Module | Test file | Must cover |
|---|---|---|
| series | `test_home_series.py` | value series equals hand-computed values for a 2-fund fixture; weekend/holiday forward-fill; first transaction mid-period; redemption; fund with no NAV → partial; bulk read issues one NAV query (assert query count, guards the 1.2-29 s naive build); Modified Dietz on 3 hand cases; 1D with one point |
| benchmark | `test_home_benchmark.py` | % return over period; clip when history starts late; Smallcap 250 present; tests that asserted exactly four indices updated; recommendation per cap-mix bucket |
| summary | `test_home_summary.py` | wording for gain/loss/flat/weekend; first vs repeat visit; scope label; "n of n" counts only members with a confirmed `Import`; no PAN/statement date in the line |
| movers | `test_home_movers.py` | **reconciliation:** gains + losses + others == net == 1D headline for fund, category and sector views; sector view reconciles even with unmapped sectors; coverage under 50% → category fallback; holiday; one fund; all down; units bought on the NAV date use previous-close units |
| allocation | `test_home_allocation.py` | donut equals Dashboard allocation for the same scope; coming-soon classes listed, not valued; family bar sums to total; hidden in member scope |
| worth | `test_home_worth.py` | each signal on/off at its threshold; max 3, most severe first; empty returns no cards; 3-month bar omitted when disclosure missing |
| api | `test_home_api.py` | auth and ownership (another user's member → 404/403 as Dashboard); aggregate vs member routes; Home totals == Dashboard totals for the same synthetic statement |
| news | `test_news_*.py` | file parsing from fixtures; allow-list; English filter; matcher ladder order; majority-class override; top-5-per-kind and minimum size; 24 h expiry; "keep last specific"; kill switch; stale 36 h / hidden 72 h; foreign names only for holders; exposure chip hidden under 50% coverage; heartbeat called on success only |
| retention | `test_portfolio_disclosure_retention.py` (existing, updated) | newest N months per scheme kept (N from N1), older batches pruned, a scheme with a late file keeps its months |
| migration | `test_migration_0044_*` | upgrade/downgrade for `news_items`, `nse_symbol`, enum value |

**Synthetic gate (F6):** run every number through the synthetic CAS set (`Docs/CAS Files/synthetic/pdfs/realistic/`), and spot-check Chandra and two real statements locally (never committed). Required scenarios: single member; several members; partial data; stale statement; no holdings; weekend/holiday; loss day; all funds down; one fund only; custom range older than index data. Headline, graph end point, contributors and summary sentence must agree to the paisa.
