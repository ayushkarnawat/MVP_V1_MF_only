## 4. Environment gotchas (these cost time)
- Git Bash mangles WSL paths: run WSL work through **PowerShell** `wsl.exe -d Ubuntu --cd <wsl path> -- bash <script>` using script files with LF endings written under the session scratchpad (`sed -i 's/\r$//'`). Windows tools can read/write WSL files via `\\wsl.localhost\Ubuntu\...`. In the Bash tool `gh ... --jq '<expr>'` works; in PowerShell a jq string with spaces is split.
- Shared Python venv: `/mnt/d/Unifolio code/backend/.venv/bin/python`. `date.today()` in the Dashboard XIRR module is the real date: tests that depend on it pin it (`pinned_xirr_clock`).
- Do not switch branches in the main checkout while a worker runs; each lane has its own worktree. A packet's Step 0 requires the red-test commit message to START with the exact text it names (check `grep -n "expect the top line"`).
- Antigravity opens the folder as `W:\home\ayush\wt\<name>` (`net use W: \\wsl.localhost\Ubuntu`); Gemini runs commands via `wsl.exe -d Ubuntu --cd ...`.
- The staging VM `deploy@ls-staging.unifolio.in` takes the owner's SSH key; this machine's key was refused earlier from session 1, so the owner (or a session where it works) runs VM commands; an SSH timeout (not refusal) is the CloudPe Security Group IP allowlist.
- Usage: check with `ccd_session_mgmt get_usage`; subagents count toward your own limit, so bundle and delegate wisely.
