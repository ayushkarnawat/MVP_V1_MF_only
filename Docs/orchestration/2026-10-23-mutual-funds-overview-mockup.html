Reference-vs-spec note — tab navigation (revised, supersedes the earlier read)

This overrides design.md §2's "vertical column" text — design.md needs a follow-up edit to match. Design.md §2 had locked this page's own in-page sub-navigation (Overview/Performance/Allocation/Holdings/ Transactions/Overlap/Other Analytics) as a vertical column, reasoning that no reference showed that nav in situ. Owner review (2026-10-24) explicitly asked for the same horizontal pill-bar visual pattern to be reused for this page's seven sub-pages instead — i.e. relabel the pattern, not copy its asset-class content.
