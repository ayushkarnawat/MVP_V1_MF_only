## The contract (fixed here; do not rename or reshape)
`backend/scripts/export_look_gate.py`, run from `backend/` as `python scripts/export_look_gate.py <command> ...` (follow `scripts/run_analytics_recompute.py` for the `sys.path` and logging style; also expose `def main(argv: list[str] | None = None) -> int` and pure functions the tests call: `capture(pdf_path, out_dir, dpi=72) -> dict` and `compare(baseline_dir, candidate_dir, max_diff_ratio=0.0005, mask=None, allow_pages=()) -> CompareResult`).
```
python scripts/export_look_gate.py capture --pdf PATH --out DIR [--dpi 72]
    # renders every page to DIR/page-001.png, page-002.png, ... (zero padded to 3 digits; pypdfium2 render at scale dpi/72, to a Pillow image, saved as PNG)
    # writes DIR/manifest.json: {"page_count": N, "sections": {"<id>": first_page, ...}, "text_sha256": ["<sha256 hex of the page's text, whitespace-collapsed>", ...]}
python scripts/export_look_gate.py compare --baseline DIR --candidate DIR [--max-diff-ratio 0.0005] [--mask FILE] [--allow-pages "1-3"]
    # exit 0 only if: same page_count; same "sections" mapping; and, for every page NOT in --allow-pages: equal text hash AND the share of differing pixels <= max-diff-ratio outside the mask regions
    # a page whose image size differs counts as differing (ratio 1.0)
    # prints "page N: differs (x.xxxx%)" for each failing page (percentage with 4 decimals), "page_count: A != B" or "sections differ" lines for the structural failures, and a last line "PASS" or "FAIL"; exit code 0 on PASS, 1 on FAIL, 2 on usage errors
    # NEVER prints any text content of a page, any section id value beyond what the failing line needs, or any file path of a page image
--mask FILE is JSON {"pages": {"1": [[x0,y0,x1,y1], ...]}} (pixel rectangles of the captured resolution; pages 1-based) for volatile areas (a cover date): pixels inside a mask rectangle are ignored on that page; the text hash of a page that has a mask entry is NOT compared (text can change with the date) while its image still is, outside the masks.
--allow-pages "1-3,7" lists pages allowed to differ in text and pixels (the contents page numbers); the page counts and section start pages must still match.
```
**Pixel difference:** convert both images to RGB, count pixels where any channel differs by more than **8** (a small tolerance for anti-aliasing noise), divide by the pixel count outside the mask. Use Pillow (`ImageChops.difference` and a point threshold) so it stays fast for 100 or more pages; do not load every page of a large report into memory at once (compare page by page).
**Not built:** any `make-pdf-export` command. The real PDFs come from the running system.
