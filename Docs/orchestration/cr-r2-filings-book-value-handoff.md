Use instead: first GET `https://www.nseindia.com/companies-listing/corporate-integrated-filing` (cookie), then `GET https://www.nseindia.com/api/integrated-filing-results?index=equities&symbol=<SYMBOL>&type=Integrated%20Filing-%20Financials`. A symbol query returns that company's full history (TCS: 14 rows, newest quarter ended 30-SEP-2026, broadcast 8 Oct 2026); a query with no symbol returns only the latest 20 filings market-wide, so query per symbol. Each row has `qe_Date`, `consolidated` (Consolidated or Standalone), `audited`, and `xbrl` (a bare XML file on `nsearchives.nseindia.com`; there is also an `ixbrl` HTML view and a PDF). **The balance sheet is in the March and September filings only** (the June and December ones carry no equity items), so book value is read from the newest March or September row with an `xbrl`, preferring Consolidated.
**The facts (namespace `www.sebi.gov.in/xbrl/<date>/in-capmkt`, units INR, unscaled, balance-sheet date as an instant context).** Non-bank (TCS, 30 Sep 2026): `EquityAttributableToOwnersOfParent` 1,189,860,000,000; `EquityShareCapital` 3,620,000,000; `OtherEquity`; `Equity`; `PaidUpValueOfEquityShareCapital` 3,620,000,000; `FaceValueOfEquityShareCapital` 1 (unit INRPerShare). So shares = paid-up capital / face value (3.62 billion) and book value per share = equity attributable to owners / shares (about 328.69). Bank (HDFC Bank, 30 Sep 2026, no total-equity fact): `PaidUpValueOfEquityShareCapital` 15,418,600,000, `ReservesAndSurplus` 6,019,271,900,000, face value 1, so book value = (paid-up capital + reserves) / shares (about 391).
