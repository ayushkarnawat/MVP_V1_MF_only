## The rule (already in the app after Task 1; the scripts must now mirror it)
Each period's average is built over the funds that **have a return for that period** (`period_members(detailed, "1Y" | "3Y" | "5Y")`): a fund joins the 1Y average if it has a 1Y return, the 3Y average if it has a 3Y return, the 5Y average if it has a 5Y return. **There is no longer a 3-year floor for the 1Y or 5Y period.** The size weighting and "funds without size" handling per period are unchanged. The **blended single figure** (`_legacy_average_from_periods`) still uses the 3Y rule (it is None when the 3Y average is None). The app's loaders are the source of truth: `category_ranking.load_peer_returns(db, scheme, today, peers=...)` (short-history peers included), `load_category_pool` and `category_period_weighted_averages`.
