## The contract (fixed here; do not rename or reshape)
```python
# backend/app/services/export/timing.py (new)
@dataclass
class ExportTimings:
    slot_wait_ms: int | None = None      # waiting for a browser slot (acquire_browser)
    browser_start_ms: int | None = None  # cold launch, 0 when pooled; None if it cannot be told apart (then leave None and say so in the report)
    goto_ms: int | None = None
    build_wait_ms: int | None = None
    pdf1_ms: int | None = None           # the first page.pdf
    contents_ms: int | None = None       # the whole contents pass, whatever its outcome
    contents_outcome: str = "skipped"    # "done" | "timeout" | "error" | "mismatch" | "skipped"
    store_ms: int | None = None
    def log_fields(self) -> str          # "slot_wait_ms=12 browser_start_ms=0 goto_ms=... contents_outcome=timeout"; a None value prints as "-"
```
`run_export` creates one `ExportTimings`, fills it with `_clock()` marks **around the existing calls** (convert seconds to whole milliseconds), and, in the existing `finally`, logs **one extra line** right after the unchanged `export finished: ...` line:
`export timing: <log_fields> pdf_bytes=<n> proxied_requests=<n>`.
`contents_outcome`: `skipped` when `options.cover` is false; `done` when the candidate replaced the PDF; `timeout` when the `wait_for` raised `TimeoutError`; `error` for any other exception; `mismatch` when `_second_pdf` returned `None`. `proxied_requests`: use the proxied-request count if `network_guard` already keeps one; **if it does not, omit that field and say so in the report** (do not add counting behaviour: the existing `blocked_requests` is on the finished line).
**Privacy rule:** the line holds only durations, the outcome word and two counts: **no user id, name, email, folio, amount, section id or job id**.
**Not changed:** the job status values, error codes, stages, the PDF bytes, the second pass itself, the existing `export finished` format, any route, any setting, the front end, migrations.
