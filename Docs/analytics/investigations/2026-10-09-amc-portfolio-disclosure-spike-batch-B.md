**Bajaj Finserv Mutual Fund — NEEDS_INVESTIGATION.** A browser-UA request was tried against the AMC root and `/sid-disclosure`, followed by a headless/browser-indexed inspection and an obvious recent-month search. The AMC-hosted workbook remained hidden, while an NSE attachment for May 2026 proved that a monthly portfolio exists. A follow-up should capture the XHR while changing the year/month or scheme selector on `/sid-disclosure`.

**Zerodha Mutual Fund — NEEDS_INVESTIGATION.** Plain HTTP returned the disclosures page and many direct CDN links for adjacent reports, but the Portfolio Disclosures block contained only scheme/period controls. The headless attempt did not recover a portfolio request after selector interaction. The next pass should inspect the page's API calls while selecting a scheme and month; the observable architecture strongly suggests a CDN XLSX behind that request.

**Unifi Mutual Fund — NEEDS_INVESTIGATION.** Plain HTTP and the rendered page both exposed the correct statutory-documents section, but the monthly list available to the trace stopped at September 2025. An obvious current-month URL search found third-party August 2026 holdings derived from Unifi disclosures, not the primary file. The blocker is therefore stale/cached AMC page data or a newer endpoint not represented in the returned markup.

**Abakkus Mutual Fund — NEEDS_INVESTIGATION.** Plain HTTP exposed empty year/month selectors, while recent first-party notices (through September 2026) confirmed that the underlying monthly statements exist. The browser trace did not return the selector's data request or a workbook URL. A later pass should drive both selector values and capture the resulting XHR; the half-yearly and notice links alone are not substitutes for the monthly stock-level file.

**JM Financial Mutual Fund — NEEDS_INVESTIGATION.** The portfolio-disclosure route was tried directly with a browser user agent, then through the rendered/indexed view. The direct body was empty and no backing API request or downloadable file was recovered. A current third-party listing was used only to confirm that August 2026 exists, not as evidence of first-party machine fetchability.

**ICICI Prudential Mutual Fund — NEEDS_INVESTIGATION.** Plain HTTP against the AMC downloads area exposed no usable monthly link. A browser/rendered follow-up and an obvious search for recent XLSX disclosures found only the AMC landing page plus a third-party monthly archive; no stable first-party API/CDN URL was obtained. This merits a focused DevTools/XHR pass because the content is known to exist but the source remains opaque.
