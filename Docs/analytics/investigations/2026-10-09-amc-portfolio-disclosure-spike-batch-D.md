Bandhan Mutual Fund — Plain retrieval found the official detailed-scheme-portfolio hub and current 2026 monthly entries in the server-indexed representation. The local `requests` attempt failed at sandbox DNS resolution, preventing the required file download and spreadsheet inspection; without that evidence the result remains `NEEDS_INVESTIGATION`.

Jio BlackRock Mutual Fund — The official notices page returned current monthly-portfolio notices, distinct from its AUM and daily-portfolio pages. The actual attachment/portfolio target was not exposed in the plain representation, and a live browser trace was unavailable because public DNS is disabled in the execution sandbox.

Navi Mutual Fund — The correct official portfolio page was found. Its unparameterized plain response contains selectors but reports no files, which strongly indicates state-backed API loading. Browser execution could not reach the public host from the sandbox, so the year/month request and resulting spreadsheet could not be captured.

Bank of India Mutual Fund — The official investor-corner page and current scheme documents both identify the `#t2` monthly-portfolio tab, but no recent file link appeared in the returned page. The unresolved item is the tab's backing request, not the existence of the disclosure obligation.

Mahindra Manulife Mutual Fund — A current official scheme document supplied the downloads-page monthly-disclosure anchor. The file listing itself was not present in the plain response available to this run, and the network-disabled local Chromium could not reveal the backing request.

Edelweiss Mutual Fund — The official notice archive proves that current monthly portfolio disclosures are being posted, but it did not expose the underlying stock-level spreadsheet through the plain document list. The remaining work is to follow the notice attachment or trace the portfolio-download request and inspect the resulting workbook.

AlphaGrep Mutual Fund — This is not a scheme-less AMC: exchange notices confirm July and August 2026 allotments. The blocker is discovery of the AMC's disclosure/download surface; no monthly workbook was indexed, while a direct browser trace could not run against the public host.

Wealth Company Mutual Fund — The official portfolio hub and separate monthly route were found, and AMFI independently identifies the sponsor as Pantomath. The page design reuses a single download target in its plain representation, so a live request trace is needed to recover the actual workbook URL and confirm columns.

Monarch Networth Mutual Fund — The official site exposes current fortnightly Overnight Fund spreadsheets but no monthly category in the returned navigation. This may reflect a genuinely fortnightly-only first-scheme implementation or a missing UI state; a later pass should test for an unlinked `/monthly` sibling route and inspect one month-end workbook.

HDFC Mutual Fund — The portfolio page is reachable and therefore differs from the prior factsheet-page 403 result. Search-indexed server output exposes recent XLSX names, while the fresh unparameterized response says “No result found”; the likely missing input is a year/filter/API state.
